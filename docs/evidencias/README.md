# Evidências de avaliação

Resultados de ensaios devem identificar comando, versões, ambiente e limites. Logs de testes não comprovam validação com usuários nem atributos fora do recorte executado.

Os logs brutos `*.txt` desta pasta são artefatos locais, ignorados pelo Git e não distribuídos. Para registrar nova execução, salve a saída localmente e atualize o relatório correspondente com método, ambiente, resultados e limites, sem credenciais ou dados pessoais.

As evidências de BL-01 e sua interpretação são apresentadas em [11 — Prova de consistência da agenda](../11-prova-consistencia-agenda.md).

As evidências de BL-02 estão em [12 — Base executável e identidade](../12-base-identidade.md), com saída da suíte e verificação adicional de inicialização. A revisão visual não foi concluída por indisponibilidade do navegador.
